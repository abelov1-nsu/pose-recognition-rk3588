In order:
pose_test - test whether yolov8 works at all on your machine

python collect.py   : Collect - record live footage
python extract.py   : Extract - get keypoints for model
python train.py     : Train - make model work with keypoints
python recognize.py : Recognize - run recognition on footage


or using:
python extract.py && python train.py && python recognize.py

use on video with:
python recognize.py --no-video --source video.mp4
(--no-video is optional)

use on screen with: (not tested, uses mss)
python recognize.py -- source screen
(mss numbers physical monitors starting at 1. Monitor 0 means the combined virtual desktop, which we won't use.)
